“Nós somos aquilo que fazemos repetidamente.

Excelência, então, não é um ato, mas um hábito.”

DURANT, 1926, tradução nossa

Começo com uma frase de Will Durant: nós somos aquilo que fazemos repetidamente; excelência não é um ato, mas um hábito. Isso vale muito para as lutas. A técnica, a faixa e os benefícios para a saúde vêm com a repetição dos treinos. O problema é que muita gente para antes de criar esse hábito.
