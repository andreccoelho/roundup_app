## Ocorrências durante o deploy

1. **Erro final no `firebase deploy`:** "Functions successfully deployed but could not set up cleanup policy in location us-central1". As funções subiram normalmente; o erro interrompeu o fim do comando, então o Hosting foi republicado separadamente com `npx firebase deploy --only hosting` (release concluído).
2. **404 temporário em `web.app`:** logo após o release, `web.app` respondeu 404 ("Site Not Found") enquanto `firebaseapp.com` já respondia 200. Normalizou em segundos (propagação); `web.app` passou a responder 200.
3. **Índice fora do arquivo:** o Firebase informou 1 índice existente no projeto que não consta em `firestore.indexes.json`. Não foi removido (exigiria `--force`).

```
# backend

```
